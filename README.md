# bMobile – instalační balíčky

Tady jsou instalační a aktualizační balíčky programů bMobile: Smart Reader Server, Smart Print a bMobile Správce. Zdrojový kód tu není.

Balíčky stahuje a instaluje bMobile Správce sám. Ručně stačí stáhnout jeho instalátor: soubor `bMobile-Spravce-Setup-<verze>.exe` u posledního vydání s názvem „bMobile Správce“.

Podpora: podpora@bmobile.cz, <https://bmobile.cz>
